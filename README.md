# SB-Talker (Schulbegleitung Dokumentation / HPG)

Eine 100 % lokale Offline-Web-App zur strukturierten Verlaufsdokumentation im Schulalltag und für Hilfeplangespräche (HPG) – ohne Server-Übertragung und mit optionaler AES-256-GCM-PIN-Verschlüsselung.

👉 **[Hier klicken, um den SB-Talker direkt als Web-App zu öffnen](https://konzept23.github.io/sb-talker/)**

### Auf dem Smartphone als eigenständige App ablegen
1. Den Link oben im Smartphone-Browser öffnen (**Chrome** auf Android / **Safari** auf dem iPhone).
2. Im Browser-Menü **„App installieren“** bzw. **„Zum Startbildschirm hinzufügen“** (iPhone: Teilen-Symbol → **„Zum Home-Bildschirm“**) wählen.
3. Der SB-Talker erscheint mit eigenem Logo auf dem Startbildschirm und läuft getrennt vom normalen Browser-Tab komplett offline.
